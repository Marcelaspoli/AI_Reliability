
# AI Reliability Lab

An AI evaluation platform designed to identify errors, inconsistencies, and reliability issues in AI-powered applications.

## Project Goal

Build an automated testing system that evaluates AI responses, detects incorrect information, and measures reliability across different models and configurations.

## Initial Use Case

SouthStar is a fictional online store with a customer-support AI assistant.

The system will test whether the assistant provides correct answers based on documented company policies.

## Planned Features

- Automated AI response testing
- Hallucination and factual error detection
- Consistency testing
- Model performance comparisons
- Reliability metrics and visualisations
- Interactive evaluation dashboard

## Technologies

Python, Pandas, SQL, Machine Learning, AI APIs
